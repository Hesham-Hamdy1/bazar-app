# Bazar App

A mobile bookstore app built with Flutter: sign up, browse the catalog,
track your orders and manage your profile.

## Getting Started

```bash
flutter pub get
flutter run
```

## Project structure

- `lib/pages` - screens grouped by feature (intro, auth, shop, account)
- `lib/shared` - reusable widgets (buttons, text fields, keypad, ...)
- `lib/core` - theme and design tokens
- `lib/routes.dart` - navigation routes

## Tests

```bash
flutter test
```
